## 1. Tổng Quan Công Việc Đã Thực Hiện

Theo yêu cầu của người dùng trên component `<BocaoTab />` (`static/js/components/bocao-tab.js`), hệ thống đã được nâng cấp toàn diện hai tính năng chiến lược:

1. **Cào toàn bộ các trang bố cáo có sẵn (`crawl_all`):**
   - Vượt qua cơ chế phân trang WebForms phức tạp của ASP.NET (`ctl00$C$CtlList`, `Page$2`, `Page$3`...) bằng cách bảo toàn và gửi động các hidden tokens: `__VIEWSTATE`, `__EVENTVALIDATION`, và `ctl00$hdParameter`.
   - Lưu trữ an toàn chống trùng lặp vào CSDL PostgreSQL `bocao_records` (`ON CONFLICT (tin, pub_time, announcement_type) DO NOTHING`).

2. **Tra cứu doanh nghiệp trực tuyến từ API `Srv.aspx/GetSearch` của DKKD:**
   - Cơ chế lấy động token xác thực `ctl00_hdParameter` từ phiên hiện tại trên cổng Bố Cáo Điện Tử, giải quyết triệt để lỗi hết hạn token cứng.
   - Trích xuất đầy đủ hồ sơ doanh nghiệp phong phú từ Apache Solr của Bộ Kế hoạch & Đầu tư: Tên công ty, Tên tiếng Anh (`Name_F`), Tên viết tắt (`Short_Name`), Mã số thuế (`Enterprise_Gdt_Code`), Mã số ĐKKD (`Enterprise_Code`), Người đại diện pháp luật (`Legal_First_Name`), Địa chỉ trụ sở chính (`Ho_Address`).

## 4. Kết Quả Kiểm Thử & Xác Thực

1. **TypeScript Type Safety:**
   - Lệnh kiểm tra: `npx tsc --noEmit`
   - Kết quả: **0 lỗi** (Thành công tuyệt đối).
2. **Kiểm tra API Fastify:**
   - `POST /api/bocao/crawl-all` (payload: `{ "max_pages": 2 }`): HTTP 200, phản hồi `{ success: true, pages_crawled: 2, total_found: 40, new_inserted: 0 }`.
   - `POST /api/bocao/dkkd-search` (payload: `{ "search_field": "2500785751" }`): HTTP 200, trả về 1 doanh nghiệp đầy đủ thông tin pháp lý từ Solr.
3. **Line Limit Rules:** 100% các tệp đều tuân thủ nghiêm ngặt chuẩn kiến trúc dòng code của dự án.

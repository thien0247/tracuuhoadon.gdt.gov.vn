# Báo Cáo Nghiệm Thu: Chuẩn Hóa Dữ Liệu Sync Theo API & Giám Sát Tiến Trình Real-time

Đã hoàn thành toàn bộ yêu cầu của người dùng về việc **khắc phục dữ liệu sync không chính xác, chỉ cập nhật khi query API tồn tại**, bổ sung **thanh tiến trình trong quá trình sync**, thống kê **số lượng thành công, thất bại, thời gian, % thành công, % thất bại**, và tái cấu trúc prompt thành đặc tả kỹ thuật hoàn chỉnh.

## 1. Tóm Tắt Các Thay Đổi Kiến Trúc & Nghiệp Vụ

### 1.1. Nguyên Tắc Cập Nhật Dữ Liệu Nghiêm Ngặt (API-Verified Only)
- **Loại Bỏ Phỏng Đoán Heuristic:** Xóa bỏ hoàn toàn cơ chế tự ý gán `org_type = CASE WHEN ...` hoặc địa chỉ giả định khi chưa có xác nhận từ API.
- **Xác Thực Kết Quả Truy Vấn:**
  - Chỉ khi gọi API Xinvoice (hoặc dịch vụ thuế) trả về trạng thái HTTP 200 và NNT thực sự tồn tại (có `taxID`/`tin` và `orgType`/`name`/`address`), hệ thống mới cập nhật vào CSDL `tax_records` và tăng biến đếm `successCount`.
  - Nếu API trả về `404 (Không tìm thấy)` hoặc lỗi kết nối: Hệ thống ghi nhận vào `failedCount`, tuyệt đối không ghi đè dữ liệu rác.
- **Tính Năng Làm Sạch Dữ Liệu (Reset Unverified):**
  - Cung cấp endpoint `POST /api/enrichment/reset-unverified` và nút bấm `🧹 Làm Sạch Dữ Liệu Cũ` trên UI, cho phép dọn dẹp các bản ghi từng bị cập nhật suy đoán sai lệch trước đây về trạng thái chờ đồng bộ chuẩn.

### 1.2. Module Quản Lý Job Đồng Bộ Nền (`src/modules/enrichment/enrichment.job.ts` - 149 dòng)
- Class `EnrichmentJobManager` độc lập quản lý vòng đời các job đồng bộ API:
  - Khởi tạo tiến trình nền rate-limited (3.2s / request tuân thủ Cloudflare WAF).
  - Thu thập và tính toán số liệu thống kê thời gian thực:
    - `totalToProcess`, `processedCount`
    - `successCount`, `failedCount`
    - `elapsedSeconds`, `estimatedSecondsRemaining` (ETA)
    - `successRate (%)`, `failureRate (%)`
    - `progressPercent (%)`
    - `currentTin` (MST đang truy vấn trực tiếp)
  - Hỗ trợ dừng tức thời an toàn (`stopJob`).

### 1.3. Giao Diện Người Dùng VDDS Mới
- **Sub-component [`enrichment-progress.js`](file:///c:/tracuuhoadon.gdt.gov.vn/static/js/components/enrichment-progress.js)** (105 dòng):
  - Hiển thị bảng điều khiển nổi bật với viền sáng indigo, chấm nhấp nháy phát sáng trạng thái.
  - Thanh tiến trình lớn với dải màu gradient (Indigo -> Purple -> Emerald).
  - **4 Thẻ Đo Lường Real-time:**
    1. **Thành Công (API Tồn Tại):** Số lượng bản ghi + tỷ lệ `% Thành công` (xanh lá).
    2. **Thất Bại / Không Tìm Thấy:** Số lượng + tỷ lệ `% Thất bại` (đỏ/cam).
    3. **Thời Gian Đã Chạy:** Đồng hồ `mm:ss`.
    4. **Ước Tính Còn Lại (ETA):** Đồng hồ `mm:ss`.
  - Nút bấm `⏹ Dừng Đồng Bộ` can thiệp ngay lập tức.
- **Component [`enrichment-tab.js`](file:///c:/tracuuhoadon.gdt.gov.vn/static/js/components/enrichment-tab.js)** (177 dòng):
  - Nhúng live progress card, polling tiến trình 1.5s/lần khi có job chạy.
  - Tích hợp nút `🧹 Làm Sạch Dữ Liệu Cũ` và nút `🔄 Sync API` cho từng tỉnh.

## 3. Bằng Chứng Nghiệm Thu API & Cơ Sở Dữ Liệu

### 3.1. Dọn Dẹp Dữ Liệu Suy Đoán Cũ
```bash
POST /api/enrichment/reset-unverified  {"prefix": "49"}
```
Phản hồi:
```json
{
  "message": "Đã dọn dẹp 39804 bản ghi về trạng thái chờ đồng bộ chuẩn từ API",
  "affectedRows": 39804
}
```

### 3.2. Chỉ Cập Nhật Khi API Tồn Tại
- **Với MST tồn tại (`4900127704`):**
  ```json
  {
    "tin": "4900127704",
    "norm_name": "Bùi Thị Giang",
    "org_type": "Doanh nghiệp / Đơn vị sự nghiệp công lập",
    "address": "Chợ Mẹt., Xã Hữu Lũng, Lạng Sơn",
    "tax_department": "Thuế cơ sở 1 tỉnh Lạng Sơn",
    "source": "xinvoice_api"
  }
  ```
- **Với MST không tồn tại (`9999999999`):**
  ```json
  { "error": "Không tìm thấy dữ liệu cho MST này" }
  ```
  *(Không có bất kỳ dữ liệu suy đoán nào được cập nhật vào CSDL).*

### 3.3. Dữ Liệu Trạng Thái Job Thời Gian Thực

```json
{
  "prefix": "49",
  "provinceName": "Lạng Sơn (49)",
  "isRunning": true,

  "successCount": 1,

  "failureRate": 0,

  "lastMessage": "Đang tra cứu API Xinvoice: 4900100050"
}
```

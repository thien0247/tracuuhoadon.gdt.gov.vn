## 1. Chi Tiết Các Thay Đổi Theo Từng Sprint

### 1.1. Sprint 1 (Quick Wins — 7 Fixes)
- [x] **`crawler_core/validator.py`**: Khắc phục bug phát sinh TIN 11 chữ số khi `rem == 0`. Bọc guard `if rem != 0` an toàn.
- [x] **`server_app/core/config.py`**: Bổ sung `rate_limiter.set_rate(val)` trong `save_system_config()` để cập nhật tốc độ RPS runtime khi user đổi qua giao diện.
- [x] **`server_app/core/database.py`**: Thay kết nối rời rạc bằng `SimpleConnectionPool(1, 5)` kèm context manager `get_db_connection()`, tuân thủ chuẩn connection pool.
- [x] **`server_app/core/state.py`**: Thay `asyncio.Lock()` bằng `threading.Lock()` tương thích an toàn với môi trường đa luồng của crawler workers.
- [x] **`server_app/routers/crawler.py`**: Ghi log lỗi vào `state.logs` trong `_staggered_start_all` thay vì nuốt ngoại lệ im lặng.
- [x] **`server_app/routers/crawler.py`**: Chuyển `fetch_all_province_stats()` sang `loop.run_in_executor` để không block event loop FastAPI trong 12 giây.
- [x] **`crawler_core/engine.py`**: Giảm độ trễ stagger giữa các worker threads từ 1.0s xuống 0.1s, tiết kiệm ~4.5s cho mỗi lần khởi động tỉnh.

### 1.2. Sprint 2 (Core Fixes — 4 Fixes)
- [x] **`crawler_core/session.py`**: Tách logic HTTP ra khỏi `self.lock` với hàm helper `_do_refresh()`. Khóa lock chỉ giữ khi gán session kết quả, giải quyết triệt để nguy cơ treo luồng khi WAF circuit breaker kích hoạt cooldown 30s. Thêm `MAX_REFRESH_RETRIES = 12`.
- [x] **`crawler_core/engine.py`**: Định nghĩa `effective_gap = gap * num_workers` đảm bảo đúng ngữ nghĩa gap khi có nhiều workers chạy song song mà không bị race condition reset nhầm.
- [x] **`server_app/core/queue_manager.py`**: Xử lý trạng thái `already_running` bằng cách bỏ qua và tăng `completed_count` thay vì đưa vào `active_provinces` gây nghẽn hàng đợi.
- [x] **`server_app/routers/crawler.py`**: Reset `last_calc_times` và `last_queried_counts` tại cả 2 vị trí resume (endpoint pause và start internal), loại bỏ hiện tượng tốc độ rớt về 0 sau khi tạm dừng.

### 1.3. Tính Năng AI Inspector Mode
- [x] **`static/js/components/ai-inspector.js`**: Store `AiInspectorStore` singleton chia sẻ trạng thái `inspectorMode` (reactive ref) và component `AiComponentBadge`.
- [x] **Giao diện & Phím tắt**: Hỗ trợ phím tắt `Alt + I` toàn cục hoặc nút bấm trên sidebar để đồng loạt bật viền neon tím nổi bật bao quanh toàn bộ 6 tab components chính.
- [x] **Popover & 1-Click Prompt**: Icon `?` trực quan góc trên-phải cho phép mở popover xem thông tin component, tệp nguồn, module, mô tả, và nút 1-click copy Markdown prompt chuẩn chỉnh cho AI Agent.
- [x] **`static/css/style.css` & `templates/index.html`**: Đã tích hợp đầy đủ style viền tím neon `#a855f7` và wrap các component.

### 1.4. Sprint 3 (Enhancements — 4 Tính Năng Nâng Cao)
- [x] **Triệt tiêu N+1 Query với In-Memory TIN Cache**:
  - `Database.init_tin_cache()`: nạp toàn bộ TIN đã có của tiền tố vào `set` trong RAM một lần duy nhất lúc engine khởi tạo.
  - `Database.has_tin()`: kiểm tra qua `tin in self._tin_cache` với độ phức tạp **O(1)** (0ms), loại bỏ hoàn toàn hàng chục nghìn truy vấn `SELECT 1` đơn lẻ tới PostgreSQL trong chế độ bidirectional.
  - Tự động đồng bộ `self._tin_cache.add(tin)` mỗi khi tìm thấy MST mới qua `save_record()`.
- [x] **Khôi phục Tiến độ Quét Tích Lũy**:
  - `Database.load_progress()`: đọc `total_queried`, `total_found` đã lưu từ bảng `scan_progress`.
  - `CrawlerEngine`: tách bạch `self.total_queried` (phiên hiện tại) và `self.initial_queried` (tích lũy quá khứ). Giao diện và test kiểm tra hiển thị đúng tiến độ phiên, trong khi cơ sở dữ liệu lưu trữ tổng dồn bền vững.
- [x] **Tự Động Ghi Nhật Ký Ra Đĩa (Persistent Logs)**:
  - `PersistedDeque`: kế thừa `deque(maxlen=500)` tự động ghi mọi thông điệp log phát sinh vào tệp hàng ngày `logs/crawl_YYYYMMDD.log` (UTF-8).
  - Đảm bảo lịch sử quét không bị mất khi ứng dụng khởi động lại.
- [x] **Hàng Đợi Điều Phối Hướng Sự Kiện (Event-Driven Queue Coordinator)**:
  - `ProvinceQueueCoordinator.notify_finished()`: sử dụng `threading.Event` (`_wake_event`) để đánh thức luồng điều phối tức thời khi một tỉnh kết thúc.
  - `CrawlerEngine.on_finished`: callback được gọi an toàn trong khối `finally` của `_run()`, loại bỏ độ trễ chờ polling cứng 1.0s giữa các tỉnh trong hàng đợi cuốn chiếu.

## 1. Mục Tiêu & Kết Quả Triển Khai

Đáp ứng yêu cầu **"Bổ sung cơ chế log chuẩn"**:
1. **Module `AppLogger.cs` Tập Trung (102 dòng):** Xây dựng bộ máy ghi log chuẩn hóa dành riêng cho `GDTTaxCrawlerManager` .NET 10, đồng bộ hoàn toàn với cấu trúc cây thư mục nhật ký `logs/` chung của dự án.
2. **Định Dạng Nhật Ký Chuẩn Hóa:**
   - Cấu trúc: `[yyyy-MM-dd HH:mm:ss.fff] [LEVEL] [ThreadId] [Source] Thông điệp [Exception]`
   - Cấp độ log phong phú: `DEBUG`, `INFO`, `WARN`, `ERROR`, `FATAL`.
   - Định danh luồng (`T01`, `T02`...) giúp điều tra chính xác đa luồng giữa UI Thread và Background Worker Threads.
3. **An Toàn Đa Luồng & Tự Động Xoay Vòng (Rotation):**
   - Đảm bảo Thread-safe tuyệt đối với `lock (syncLock)`.
   - Xoay vòng file theo ngày: `logs/gui_yyyyMMdd.log`.
   - Giới hạn dung lượng an toàn (Max Size Guard): Tối đa 10 MB/file; tự động backup sang `gui_yyyyMMdd_HHmmss.log`.
4. **Tiện Ích Trực Quan Mở File & Thư Mục:**
   - Bổ sung 2 mục vào menu khay hệ thống (System Tray): `📁 Mở Thư Mục Logs` và `📝 Xem File Log Hôm Nay`.

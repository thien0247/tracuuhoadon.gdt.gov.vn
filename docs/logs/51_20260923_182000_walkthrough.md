## 1. MỤC TIÊU VÀ BỐI CẢNH
Dựa trên tài liệu thiết kế mẫu `CSHARP_WINFORMS_TEMPLATE.md`, phát triển và biên dịch công cụ đồ họa bản địa (Native C# Windows Forms) để giám sát và quản trị hệ thống Windows Service `GDTTaxCrawler` (Fastify Web Dashboard port 8123 + Python AI Worker port 8124) với tiêu chí:
- Giao diện Card Flat UI hiện đại, hỗ trợ chuyển đổi chủ đề Sáng / Tối (Light / Dark Theme) mượt mà.
- Đèn trạng thái GDI+ 3D Anti-aliased LED và giám sát kép trạng thái 2 cổng TCP (8123, 8124).
- Khay hệ thống (System Tray) với Dynamic RAM Icon (chữ 'G' đổi màu xanh/vàng/đỏ theo trạng thái dịch vụ) giải phóng GDI handle an toàn qua `DestroyIcon`.
- Console log phân màu thời gian thực, thread-safe qua `BeginInvoke`.
- Biên dịch độc lập với trình biên dịch tích hợp sẵn của Windows (`csc.exe` trong Microsoft .NET Framework v4.0.30319), không cần cài đặt thêm SDK, Visual Studio hay NuGet dependencies.

## 4. ĐẶC ĐIỂM KỸ THUẬT NỔI BẬT ĐÃ ĐƯỢC ÁP DỤNG TỪ TEMPLATE

1. **Khắc phục lỗi Docking / Anchoring Width 200px:**
   Mọi panel chứa control con có neo `Anchor = Top | Right` đều được gán độ rộng `Width` cụ thể trước khi thêm controls con vào `Controls.Add()`.
2. **Quản lý tài nguyên GDI & Tránh rò rỉ RAM (Memory Leak):**
   Mỗi lần vẽ lại icon khay hệ thống, handle icon cũ đều được hủy bỏ an toàn bằng `DestroyIcon(hIcon)`.
3. **Thao tác Service bất đồng bộ (Non-blocking UI):**
   Toàn bộ lệnh điều khiển dịch vụ (`install`, `uninstall`, `start`, `stop`, `restart`) đều được đẩy vào `ThreadPool.QueueUserWorkItem` và điều phối gọi `service.bat` qua `ProcessStartInfo` ẩn console.
4. **Giám sát kép TCP Socket & Service Controller:**
   Kiểm tra đồng thời cả `ServiceController` trạng thái dịch vụ Windows và mở kết nối socket ngắn hạn đến port 8123 (Web GUI) và 8124 (Python AI Worker).

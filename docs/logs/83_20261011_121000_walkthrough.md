## 1. Nguyên Nhân Gốc Rễ (Root Cause Analysis)

Sau khi điều tra chi tiết luồng xử lý từ Giao diện Vue 3, WebView2 .NET 10 đến Máy chủ Fastify, đã xác định được 3 nguyên nhân cốt lõi gây ra lỗi `TypeError: Failed to fetch` khi truy cập Tab Bố Cáo:

1. **Xung đột Proxy Môi trường với Local Loopback (`http://127.0.0.1:8123`):**
   - Trên máy trạm tồn tại biến môi trường `http_proxy` / `HTTPS_PROXY` trỏ tới `http://127.0.0.1:59393`.
   - Trong `MainForm.WebView.cs`, đối tượng `HttpClient` được khởi tạo bằng `new HttpClient()` mặc định mà không cấu hình `UseProxy = false`.
   - Kết quả: Toàn bộ truy vấn chuyển tiếp từ WebView2 (`https://app.local/api/*`) sang máy chủ backend nội bộ `127.0.0.1:8123` bị proxy chặn lại với lỗi `400 Direct IP access is not allowed`.
2. **Luồng dữ liệu Network Stream chưa được Buffer (`respStream`):**
   - Hàm `OnWebResourceRequested` chuyển tiếp `respStream` trực tiếp từ `response.Content.ReadAsStreamAsync()` sang `CreateWebResourceResponse`.
   - Đối tượng `msg` và `response` bị dispose hoặc thu hồi sau khi thoát phạm vi khối lệnh `try/using`, làm socket bị đóng sớm khi Chromium chưa kịp đọc hết dữ liệu, dẫn đến `Failed to fetch`.
   - Các header hop-by-hop của HTTP/1.1 (`Connection: keep-alive`, `Transfer-Encoding: chunked`) gây xung đột với bộ phân tích HTTP của Chromium trong WebView2.
3. **Xử lý lỗi bằng hàm `alert()` chặn giao diện:**
   - Trong component `BocaoTab.vue`, khi truy vấn gặp sự cố, lệnh `alert('Lỗi tải bố cáo: ' + String(e))` hiển thị popup modal chặn toàn bộ thao tác của người dùng thay vì hiển thị thông báo inline mềm mại.

## 2. Các Giải Pháp Đã Triển Khai

### 2.1. Cấu hình Bỏ Qua Proxy Tuyệt Đối Trong C# (`MainForm.WebView.cs`)
- Cấu hình `SocketsHttpHandler` với `UseProxy = false`, `ConnectTimeout = 5s`:
  ```csharp
  private static readonly HttpClient httpClient = new HttpClient(new SocketsHttpHandler
  {
      UseProxy = false, // Bỏ qua proxy môi trường trên 127.0.0.1
      PooledConnectionLifetime = TimeSpan.FromMinutes(10),
      ConnectTimeout = TimeSpan.FromSeconds(5)
  }) { Timeout = TimeSpan.FromSeconds(30) };
  ```
- Nạp toàn bộ dữ liệu phản hồi REST API vào `MemoryStream` (`ReadAsByteArrayAsync()`), loại bỏ các header xung đột (`Connection`, `Keep-Alive`, `Transfer-Encoding`), đồng thời thêm `Access-Control-Allow-Origin: *`.
- Phân luồng riêng biệt đối với SSE `/api/stream` để đảm bảo stream realtime hoạt động ổn định.

### 2.2. Khai Báo Biến Môi Trường `NO_PROXY` Trong Script Khởi Động
- Thêm `set "NO_PROXY=127.0.0.1,localhost,app.local"` vào `run_csharp_gui.bat` và `service_runner.bat`.

### 2.3. Cải Tiến Xử Lý Lỗi & Truy Vấn Bố Cáo (`BocaoTab.vue` & `client.ts`)
- `ApiClient.getBocaoRecords()`: Tự động loại bỏ các tham số rỗng trên URL và kiểm tra `res.ok`.
- `BocaoTab.vue`: Chuyển từ `alert()` sang hiển thị thông báo lỗi `errorText` trực tiếp trong bảng dữ liệu một cách trang nhã, không gây đóng băng giao diện.

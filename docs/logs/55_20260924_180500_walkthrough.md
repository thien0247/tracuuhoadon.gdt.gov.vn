## 1. MỤC TIÊU & TỔNG KẾT
Đã tích hợp thành công bộ trực quan hóa đồ thị tri thức mã nguồn `graphify-out/` (`graph.html`, `GRAPH_TREE.html`, `GRAPH_REPORT.md`) thành một Tab chức năng độc lập trực tiếp trên Web Dashboard local của hệ thống GDT Tax Crawler:
- Hỗ trợ xem trực tiếp không cần mở trình duyệt ngoài, tự động tương thích giao diện Sáng / Tối (VDDS Light / Dark Mode).
- Cung cấp bộ chuyển đổi nhanh giữa 3 chế độ xem: **Mạng Lưới (Network Graph)**, **Cây Phân Cấp D3 (Collapsible Tree)**, và **Báo Cáo Kiểm Định (Architecture Report)**.
- Tích hợp nút quét lại cú pháp AST và tái tạo đồ thị thời gian thực (`POST /api/graphify/refresh`).
- Hỗ trợ nút mở toàn màn hình sang tab mới (`window.open`).

## 4. HƯỚNG DẪN TRẢI NGHIỆM TRÊN WEB LOCAL
1. Khởi động Web Server (qua `run_server.bat` hoặc Windows Service trên port 8123).
2. Mở trình duyệt truy cập: `http://localhost:8123` (hoặc `http://localhost:8000`).
3. Trên thanh Sidebar bên trái, tìm nhóm **"Kiến Trúc & Đồ Thị"** và nhấp chọn **"Đồ Thị Kiến Trúc (Graph)"** (icon 🕸️).
4. Tại giao diện tab:
   - Nhấp **"Mạng Lưới"**: Tương tác trực tiếp với đồ thị 929 nodes và 1,858 edges (phóng to, thu nhỏ, kéo node, tìm kiếm).
   - Nhấp **"Cây D3"**: Xem cây phân cấp tổ chức toàn bộ file và module.
   - Nhấp **"Báo Cáo"**: Đọc trực tiếp báo cáo kiểm định kiến trúc, danh sách God nodes và cảnh báo import cycles.
   - Nhấp **"Làm Mới AST"**: Tự động kích hoạt quét lại toàn bộ mã nguồn khi vừa có thay đổi code.

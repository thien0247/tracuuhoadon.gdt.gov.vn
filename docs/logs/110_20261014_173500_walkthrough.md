Để đảm bảo quy chuẩn $\le 160$ dòng/tệp (Hard cap 180 dòng):

- **`SearchTable.vue` (127 dòng) [MỚI]:**
  * Tích hợp core API TanStack Table v8: `useVueTable`, `getCoreRowModel`, `getSortedRowModel`, `getPaginationRowModel`, `getFilteredRowModel`, `FlexRender`.

  * **Phân trang chuyên nghiệp (Pagination):** Dropdown chọn số dòng (10, 25, 50, 100 dòng/trang), nút chuyển trang Đầu/Trước/Sau/Cuối, hiển thị rõ ràng chỉ số dòng và trang.
  * **Ẩn/Hiện cột (Column Visibility):** Menu bật/tắt hiển thị từng cột dữ liệu tùy ý.
  * **Tải CSV nhanh:** Cho phép tải trực tiếp các dòng đang lọc/hiển thị ra tệp CSV kèm UTF-8 BOM chuẩn tiếng Việt.
  * **Tương tác trực quan:** Nút xem chi tiết MST (icon 👁️) kích hoạt sự kiện `@select-tin`.
- **`SearchTab.vue` (90 dòng) [TÁI CẤU TRÚC]:**

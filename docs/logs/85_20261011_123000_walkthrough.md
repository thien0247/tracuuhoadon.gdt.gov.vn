## 1. Bối Cảnh & Mục Tiêu (Context)
Tham khảo kiến trúc điều phối dịch vụ và cầu nối WebView2 (WebViewBridge) từ dự án `E:\muasamcong.mpi.gov.vn\service-manager`, chuẩn hóa và áp dụng toàn diện vào hệ thống GDT Tax Crawler (`C:\tracuuhoadon.gdt.gov.vn`).

### Các Trụ Cột Kỹ Thuật Đạt Được:
1. **Giao Tiếp Hai Chiều Native IPC (`WebViewBridge.cs` & `useServiceManager.ts`):**
   - Thay vì phụ thuộc hoàn toàn vào HTTP loopback (dễ bị xung đột với system proxy như đã gặp phải ở lỗi fetch), C# và Vue 3 trao đổi trực tiếp qua kênh IPC WebView2 (`PostWebMessageAsJson` và `window.chrome.webview.postMessage`).
   - Tốc độ phản hồi đạt microsecond, miễn nhiễm hoàn toàn với thiết lập Proxy của Windows.
2. **Chế Độ Lai Tự Động (Hybrid Native + Web Fallback):**
   - Khi chạy trong ứng dụng C# Desktop: Kích hoạt Native IPC.
   - Khi mở qua trình duyệt web độc lập (Chrome, Edge ngoài): Tự động fallback sang gọi REST API Fastify `/api/services/status` và `/api/services/control`.
3. **Giám Sát Trạng Thái Độc Lập Proxy (`HealthChecker.cs`):**
   - Sử dụng `TcpClient` probe socket và `HttpClient` với cấu hình `UseProxy = false`, kiểm tra chính xác trạng thái TCP port và HTTP 200 của 5 service.
4. **Hệ Thống Live Log Console (`LogManager.cs` & `ServiceLogViewer.vue`):**
   - Thu thập log từ `AppLogger`, Windows Service, Fastify API và stream theo thời gian thực tới Vue 3 với bộ lọc tiến trình, sao chép nhanh và tự động cuộn.

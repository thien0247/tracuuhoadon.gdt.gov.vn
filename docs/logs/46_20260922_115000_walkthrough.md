## 1. Mục Tiêu Nghiệm Thu

Tổ chức và tái cấu trúc lại thanh Menu Điều Hướng (Sidebar Navigation) từ cấu trúc phẳng 8 mục thành **3 nhóm nghiệp vụ logic rõ ràng** theo **Phương án A** do người dùng lựa chọn:
1. **Nhóm 1: Vét Cạn & Giám Sát** (Thu thập & điều hành tiến độ)
2. **Nhóm 2: Bố Cáo & Đối Soát** (Nguồn ĐKKD & phát hiện khoảng trống)
3. **Nhóm 3: Tra Cứu & Khai Thác** (Truy vấn, phân tích & làm giàu dữ liệu)

Đồng thời tuân thủ giới hạn dòng code nghiêm ngặt theo `GEMINI.md` đối với UI Template: **Hard Cap ≤ 220 dòng**.

## 2. Chi Tiết Thực Hiện

### 2.1. Cấu Trúc Menu Phân Nhóm Trong `templates/index.html`
- Chuyển đổi vòng lặp phẳng `nav` sang mảng 3 nhóm có tiêu đề nhóm (section title) dạng nhãn nhỏ tinh tế:
  ```html
  <nav class="space-y-2.5">
      <div v-for="(grp, gIdx) in [
          { t: 'Vét Cạn & Giám Sát', items: [
              { id: 'scan', icon: '📊', name: 'Quản Lý Quét Đa Tỉnh' },
              { id: 'health_report', icon: '🩺', name: 'Giám Sát Sức Khỏe' },
              { id: 'config', icon: '⚙️', name: 'Cấu Hình Tỉnh Thành' }
          ]},
          { t: 'Bố Cáo & Đối Soát', items: [
              { id: 'bocao', icon: '📰', name: 'Bố Cáo ĐKKD Mới Nhất' },
              { id: 'bocao_reconcile', icon: '⚖️', name: 'Đối Soát Bố Cáo & Thuế' }
          ]},
          { t: 'Tra Cứu & Khai Thác', items: [
              { id: 'search', icon: '🔍', name: 'Tra Cứu Doanh Nghiệp' },
              { id: 'filter', icon: '📅', name: 'Lọc & Xuất Dữ Liệu' },
              { id: 'enrichment', icon: '✨', name: 'Làm Giàu Thuộc Tính' }
          ]}
      ]" :key="grp.t" :class="gIdx > 0 ? 'pt-2 border-t border-[var(--border-color)]' : ''">
          <div v-show="!isSidebarCollapsed" class="text-[9px] font-bold text-[var(--text-muted)] uppercase tracking-wider px-2 mb-1">{{ grp.t }}</div>
          <div class="space-y-0.5">
              <button v-for="item in grp.items" :key="item.id" @click="activeTab = item.id" :title="item.name" ...>
                  ...
              </button>
          </div>
      </div>
  </nav>
  ```
- Duy trì đầy đủ tính năng:
  - Hiển thị badge cảnh báo tiến trình kẹt (stalled) tại mục `health_report`.
  - Tự động ẩn tiêu đề nhóm khi sidebar thu gọn (`isSidebarCollapsed = true`).
  - Phân tách thị giác rõ ràng giữa các nhóm bằng `border-t border-[var(--border-color)]`.

### 2.2. Kiểm Soát Giới Hạn Dòng Code (Line Cap Optimization)
- Gom gọn các wrapper `<ai-component-badge>` đơn lẻ (bao gồm `TaxDetailModal` và `BocaoSolrModal`) thành 1 dòng code.
- Kết quả: `templates/index.html` đạt **209 dòng** (tiêu chuẩn ≤ 220 dòng).

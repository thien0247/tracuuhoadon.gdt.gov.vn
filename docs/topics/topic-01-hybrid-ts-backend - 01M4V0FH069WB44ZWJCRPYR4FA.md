# Topic 01: Kiến Trúc Hybrid TypeScript Backend Cho GDT Tax Crawler

> **Mã số:** Topic 01 | **Ngày bắt đầu:** 19/09/2026 | **Tác giả:** AI Assistant & Pair Programmer

---

## 1. Bối Cảnh & Bài Toán Kỹ Thuật

Hệ thống GDT Tax Crawler cần đạt được 2 mục tiêu:
1. **Tuân thủ chuẩn mực Template:** Sử dụng TypeScript strict mode, module hóa phân tầng, giới hạn dòng code nghiêm ngặt (< 200 dòng/file).
2. **Đảm bảo tính ổn định của Core Crawler:** Cổng thuế GDT (`tracuuhoadon.gdt.gov.vn`) có F5 BIG-IP WAF kiểm tra TLS Fingerprint (JA3/JA4) rất chặt chẽ và CAPTCHA phức tạp. Thư viện Python `curl_cffi` và mạng TensorFlow CRNN hiện tại hoạt động cực kỳ tin cậy.

---

## 2. Giải Pháp Kiến Trúc: Hybrid Architecture

```
                  ┌──────────────────────────────────────────────┐
                  │          Vue 3 Web Dashboard (Port 8123)     │
                  └──────────────────────┬───────────────────────┘
                                         │ REST API / SSE
                                         ▼
┌────────────────────────────────────────────────────────────────────────────────────────┐
│  TypeScript Fastify Backend (Port 8123)                                                │
│  ├── Modules: provinces, records, crawler, stream                                      │
│  ├── Database: PostgreSQL connection pool (pg.Pool)                                    │
│  └── Bridge Client: Gửi lệnh crawl qua internal HTTP IPC                               │
└──────────────────────────┬─────────────────────────────┬───────────────────────────────┘
                           │                             │
                  SQL Query│                             │ Internal IPC (Port 8124)
                           ▼                             ▼
              ┌─────────────────────────┐   ┌────────────────────────────────────────────┐
              │ PostgreSQL (Port 5433)  │   │ Python Crawler Worker (Port 8124)          │
              │ - tax_records           │   │ ├── TensorFlow Keras CRNN (captcha solver) │
              │ - provinces             │   │ └── curl_cffi Chrome 124 (WAF bypass)      │
              └─────────────────────────┘   └────────────────────────────────────────────┘
```

---

## 3. Phân Chia Trách Nhiệm (Separation of Concerns)

- **TypeScript Backend (`src/`):**
  - Quản lý RESTful APIs (`/api/configs/provinces`, `/api/search`, `/api/filter`).
  - Truy vấn tối ưu PostgreSQL cho 1.1M+ bản ghi thuế.
  - Quản lý kết nối thời gian thực Server-Sent Events (`/api/stream`).
  - Phục vụ Web Dashboard và static files.
- **Python Crawler Worker:**
  - Lắng nghe lệnh khởi chạy/dừng quét từ TS Backend.
  - Quản lý phiên HTTP `curl_cffi` giả lập Chrome 124.
  - Giải mã CAPTCHA tự động bằng model AI CRNN.
  - Ghi trực tiếp kết quả vào PostgreSQL `tax_records`.
